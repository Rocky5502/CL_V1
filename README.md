# CL_V1 — Epistemic Behavioral Fairness

Reproducible experiment infrastructure for uncertainty, model behavior, and fairness research in large language models.

This repository is pre-run: no empirical findings are committed. It targets a Windows 10 Pro + WSL2 local lab with an NVIDIA GeForce RTX 5070 Ti, user-reported 48 GB accessible GPU memory pending verification, 64 GB RAM, and a 2 TB Samsung 990 PRO SSD.

Start with `docs/RUNBOOK.md`. Third-party datasets are snapshotted locally with immutable revisions and SHA-256 manifests rather than vendored into Git.

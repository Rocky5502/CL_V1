# Local experiment runbook

## 1. Verify the machine
Run the Windows hardware commands in `docs/LOCAL_SETUP_WINDOWS_WSL2.md`, then run `python scripts/preflight.py --write artifacts/preflight` inside WSL2. Do not begin model downloads until the GPU name, usable memory, driver, CPU, storage, Python, PyTorch, and CUDA runtime are recorded.

## 2. Create the environment
Run `bash scripts/setup_wsl.sh`, activate `.venv`, and keep the exported environment freeze with the experiment artifacts.

## 3. Snapshot external data
Use `python scripts/backup_datasets.py --list`, then snapshot only the resources approved for the study. After download, run the script again with `--verify`. Copy the frozen raw-data directory to a second storage location and commit only the small manifests.

## 4. Freeze models
Resolve exact Hugging Face checkpoint revisions and explicit hosted model IDs with `python scripts/freeze_models.py`. Hosted models remain disabled until credentials and model IDs are deliberately configured.

## 5. Smoke test
Run `python scripts/build_benchmark.py --pilot`, `python scripts/run_pilot.py --model mock --limit 12`, and `pytest -q`.

## 6. Confirmatory gate
The main run is blocked until the reviewed benchmark, translations, model freeze, environment freeze, annotation/classifier validation, and statistical analysis plan are signed off. The public repository does not fabricate a confirmatory benchmark.

## 7. Execute
Tier A is deterministic first-pass evaluation. Tier B is repeated stochastic generation for uncertainty estimators. Raw outputs are append-only JSONL and every prompt/response receives a SHA-256 digest.

## 8. Analyze and generate paper artifacts
Derived labels and statistics are created from raw outputs. Paper figures/tables are generated by code; never type empirical values manually into LaTeX.

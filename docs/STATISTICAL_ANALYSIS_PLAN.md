# Statistical analysis plan — pre-run

The confirmatory unit is the paired scenario family. Primary analyses compare paired condition variants while controlling for information state and estimated uncertainty rather than interpreting raw marginal group averages.

Planned analyses include within-family paired contrasts, cluster bootstrap confidence intervals, calibration/error metrics, and logistic models for epistemic actions with scenario-family clustering and model/domain/language controls. Primary hypothesis families use Holm correction; exploratory families use Benjamini-Hochberg FDR. The default cluster bootstrap uses 2,000 replicates and seed 5502.

Any confirmatory change to outcomes, model panel, benchmark construction, exclusion rules, uncertainty estimators, or multiplicity correction after inspecting real outcomes must be recorded as a protocol deviation. Null effects and estimator disagreement are reportable findings.
